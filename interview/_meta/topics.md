# Interview Topic Registry

This file defines the coarse-grained topics allowed in `interview/outlines/`.
Prefer mapping new questions into an existing topic.
If a new direction does not fit cleanly, add it to `../inbox/proposed-topics.md` and ask for confirmation before creating a new outline.

## Current Topics

- `algorithms` - data structures, algorithm design, coding patterns, complexity analysis
- `agent` - agent architecture, planning, tool use, memory, orchestration, evaluation
- `llm-application` - end-to-end LLM app patterns, product/system concerns, trade-offs
- `rag` - retrieval, indexing, chunking, reranking, grounding, freshness
- `prompt-engineering` - prompt design, control, structured output, prompt debugging
- `evaluation` - offline evals, online metrics, rubric design, failure analysis
- `model-serving` - inference, deployment, batching, caching, latency, cost
- `ai-system-design` - architecture questions spanning multiple LLM components
- `search-and-ranking` - retrieval, ranking, query understanding, relevance
- `intent-recognition` - intent classification, routing, ambiguity handling, NLU
- `memory-and-context` - context windows, long-context strategies, memory systems
- `redis` - caching, persistence, consistency, distributed locking, hot keys
- `mq` - messaging, reliability, ordering, idempotency, transactions
- `database` - transactions, indexes, replication, sharding, consistency
- `jvm` - memory model, GC, class loading, performance tuning
- `java-concurrency` - threads, locks, thread pools, async patterns
- `backend-system-design` - traffic, consistency, scalability, observability, resilience

## Topic Rules

- Keep topics broad enough to support a lecture-style outline.
- Do not create a new topic just because a single vendor or sub-feature appears.
- Promote a subtopic into a new topic only when repeated question volume and conceptual density justify it.
- New topic creation requires human confirmation.
